1. Open the address and create your account: the first account is the instance admin.
2. Admin → Settings: turn off sign-up if needed.

## Admin checks

- `BASEROW_CADDY_ADDRESSES: ":80"`: the image's built-in Caddy would otherwise try its own HTTPS and Let's Encrypt for the `https://` public URL and loop behind our proxies. TLS stays at Zoraxy.
- One Celery worker (`BASEROW_AMOUNT_OF_WORKERS`) to keep RAM down; it still needs ~1.2–1.5 GB, so it's free from Q2.
- Secrets are generated by the image on the first start and stored in the `data` volume, along with the database: back up that one volume.
